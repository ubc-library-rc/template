# Research Commons Workshop Template 
### UBC Library Research Commons 

Description: This is the *template* for producing workshop websites and presentations. It is most emphatically *not* designed to be used as is. It should be used as a template on Github, cloned or forked for use somewhere else.

### Important 

The template itself will be in the `main` branch of this repo. This documentation, and by extension, its website, is in the `documentation` branch. These two branches are not, and will not ever be, the same. **DO NOT MERGE THE DOCUMENTATION BRANCH WITH MAIN**. They will live forever apart, but knowing that each of them lives within the other.

#### Instructions

The detailed instructions on how to use this template are here:

Link to workshop: <https://ubc-library-rc.github.io/template/>

And, for some reason, if you want to view the documentation locally:

```
git checkout documentation
jekyll serve
```

The installation of [Jekyll](https://jekyllrb.com/) is left as an exercise for the reader.
